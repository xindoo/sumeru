# 玄幻风格参考库

> ⚠️ 合规要求：本文件只提供**构词法与结构模板**，不再提供成品人名清单。生成时按 `ip-blocklist.md` 的四步重构法现场造名，禁止直接套用任何知名角色名。

## 一、境界体系参考

### 通用等级模板（从低到高）
1. 淬体 → 聚气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫 → 飞升
2. 武士 → 武师 → 大武师 → 武宗 → 武皇 → 武尊 → 武圣 → 武神
3. 凡阶 → 灵阶 → 王阶 → 皇阶 → 尊阶 → 圣阶 → 神阶

### 设计要点
- 等级数量建议 7-9 级，超过 12 级读者记不住
- 每级要有**质变**而非单纯数值膨胀（寿元、感知、飞行、法则）
- 前 3 级是"爽点密集区"，升级速度要快；后期要设置瓶颈制造压抑
- 等级名要成体系（同一套意象），不要混搭

## 二、势力结构参考

### 层级模板
- 宗门：三流 → 二流 → 一流 → 顶级 → 超级 → 上古
- 帝国：公国 → 王国 → 帝国 → 皇朝 → 帝朝
- 其他：商会、冒险公会、杀手组织、丹塔、器殿、阵盟

### 命名构词
- 前缀意象：青云、丹霞、万剑、焚天、寒冰、雷神、苍梧、沉星、断岳、归墟
- 后缀：宗、门、派、阁、殿、宫、府、堂、盟、塔
- 组合规则：`意象字2-3个 + 后缀1个`，同一势力体系内后缀不重复

### 原创示例
栖霞宗、听雪门、断岳剑派、沉星阁、归墟殿、赤霄盟、九曜塔（示例仅示范构词，正式生成应重新组合）

## 三、地名构词参考

### 大陆/区域
- 构词：`方位 + 地貌` / `意象 + 域`
- 示例：东陆、西荒、南泽、北原、中州、无尽海、乱石原、霜落川、赤沙域、幽澜泽
- 禁止：直接使用真实山脉、河流、省份、景点名称

### 城市/据点
- 构词：`单字意象 + 城/镇/关/渡/坊`
- 示例：临川城、望海镇、雁回关、渡云津、青梧坊、霜城、落星渡

## 四、人名生成法（不提供成品名单）

### 男性
- 公式 A：`单姓 + 动词/意象 + 收尾字`（陆照野、江砚舟、楚怀朔）
- 公式 B：`单姓 + 单字名`，名字要"硬"（秦叙白、裴观澜）
- 收尾字池：辰、野、舟、白、澜、朔、岳、戈、珩、烬

### 女性
- 公式 A：`单姓 + 意象字 + 柔字`（沈昭宁、苏砚秋）
- 公式 B：`复姓 + 双字`（上官清晏、司徒明棠）
- 柔字池：宁、秋、棠、微、绾、星、鸢、禾、瑶

### 道号/尊号
- 公式：`形容词 + 子/真人/真君/道人`
- 示例：玄微子、清晏真人、碧霄真君、守拙道人

## 五、宝物/功法/体质构词

- 功法等级：黄 → 玄 → 地 → 天 → 神，每级分低/中/高/极品
- 宝物等级：凡器 → 法器 → 宝器 → 灵器 → 圣器 → 神器 → 先天灵宝
- 功法命名：`意象 + 诀/经/篇/录`（《九曜焚天诀》《沧溟剑经》）
- 体质命名：`属性/意象 + 体/骨/脉/瞳`（寒渊圣体、赤霄道骨、天音灵脉）
- 禁止：直接使用某部作品独创的体质名、异火名、功法名

## 六、常见爽点结构

1. **废柴觉醒**：被轻视 → 意外获得力量 → 小范围打脸
2. **越阶战斗**：敌方境界压制 → 主角底牌翻盘 → 旁观者震惊
3. **身份反转**：被当成废物 → 真实身份曝光 → 全场态度逆转
4. **资源掠夺**：秘境开启 → 争夺 → 主角独得大头
5. **宗门扬名**：外门弟子 → 大比夺魁 → 宗门资源倾斜

## 七、写作红线

- 不写现实宗教实操、不写真实民族/地域贬损
- 不照搬知名作品的"境界名+体质名+异火名"组合
- 主角金手指必须有**明确限制**，否则中期必然崩坏
- 配角智商与主角同步升级，避免"降智打脸"疲劳
