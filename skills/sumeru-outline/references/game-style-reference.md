# 游戏电竞风格参考库

> ⚠️ 合规要求：所有游戏、战队、选手、赛事、俱乐部必须虚构。禁止使用真实电竞俱乐部、真实选手 ID、真实游戏名称及其标志性角色。

## 一、题材分类

### 游戏类型
- MMO：副本开荒、公会争霸、全服首杀、装备打造
- FPS：战术射击、大逃杀、爆破模式
- MOBA：对线运营、团战、职业联赛
- 全息 VR：沉浸式体验、意识操作、痛觉同步
- 卡牌/策略：构筑卡组、天梯上分
- 生存沙盒：基建、开荒、PVP 夺资源

### 电竞细分
职业联赛文、退役复出文、天才新人文、网吧大神文、女子战队文、教练/经理文、解说视角文

## 二、赛事体系

### 晋升线
网吧赛 → 城市赛 → 高校联赛 → 次级联赛 → 顶级职业联赛 → 季后赛 → 国际邀请赛/世界总决赛

### 赛制
- 常规赛：BO1/BO3 积分制
- 季后赛：BO5 淘汰制
- 世界赛：小组循环 + BO5 淘汰
- 关键规则：换人限制、暂停规则、版本更新影响

### 位置分工
- 射击：指挥、突击手、狙击手、自由人、辅助
- MOBA：上单、打野、中单、射手、辅助
- 通用：队长、核心 C 位、替补、数据分析师、教练、领队

## 三、虚构命名法

### 游戏名
- 公式：`意象 + 之境/纪元/战场/领域`（《苍穹之境》《星海纪元》《破晓战场》）
- 发布前检索是否与真实游戏重名

### 战队名
- 公式：`城市/意象 + 动物/自然`（南岭苍狼、临江白鲸、赤霄鸢、北岭钢牛）
- 禁止：真实俱乐部名、真实俱乐部缩写

### 选手 ID
- 风格池：单字（烬、刃、霜）、意象（断桥、孤影、晚风）、英文（Nine、Zero、Kite）
- 禁止：真实选手 ID、知名电竞 ID

### 本名
- 男：陆之昀、江叙白、沈聿、方景年、闻笛、池羽
- 女：温向晚、许诺、商陆、桑野

## 四、常见金手指

重生回到职业生涯起点、超凡反应手速、数据化视野（弹道预测）、全位置精通、伤病复原体质、系统级意识、天赋觉醒（鹰眼/绝对专注）、跨游戏全才、粉丝加持

### 设计要点
- 金手指要"能解释赢"，但不能"直接等于赢"
- 手伤、年龄、版本更新是天然的压制机制
- 团队项目要写配合，不能一个人打五个（除非设定为碾压流）

## 五、角色配置

天才新人（张扬/寡言两派）、过气老将、魔鬼教练、毒舌解说、美女领队、数据宅分析师、富二代老板、宿敌选手、网恋对象=对手

## 六、经典桥段

逆风翻盘让二追三、绝境一穿三、天价转会、代打/开挂污蔑、手伤隐瞒出战、退役仪式、网吧路人王吊打职业、双排上分奔现、老将重返世界赛、新王加冕、赛前垃圾话、赛后采访名场面、队友内讧到和解、青训营魔鬼考核

## 七、写作要点

- 战斗描写强调"操作细节 + 临场决策"，不能只喊招式名
- 核心爽点：实力碾压、逆袭翻盘、荣誉加身、团队羁绊
- 数据要自洽：经济差、装备差、等级差要能对上
- 版本更新是天然的剧情转折点，可用于制造困境
- 所有战队/选手/赛事名必须虚构，避免映射真实电竞圈
