# 言情风格参考库

> ⚠️ 合规要求：禁止使用知名言情/影视作品的男女主姓名与其标志性人设组合；宫廷题材禁止使用真实宫殿名、真实朝代官署名。本文件提供类型模板与构词法。

### 架空言情

## 二、人物类型

### 男主类型
霸道总裁、冰山学长、腹黑权臣、温柔王爷、邪魅魔尊、禁欲上仙、忠犬小奶狗、痞帅校草、深情霸总、冷酷杀手、神医、兵王、残疾大佬、失忆总裁、偏执病娇

### 女主类型
软萌甜妹、飒爽大女主、逆袭庶女、天才医女、穿越特工、傲娇千金、落魄千金、学霸校花、职场女强人、单亲妈妈、重生复仇、炮灰逆袭、穿书女配、清冷仙女

### 设计要点
- 男女主要有**互补缺陷**，不能两个完人谈恋爱
- 反派女配不要写成纯工具人，给她一个自洽的动机
- 甜宠文也要有冲突，否则 20 章后无戏可写

## 三、人名生成法

### 男主
- 公式：`单姓 + 双字意象`（顾行舟、沈叙白、陆照野、裴观澜）
- 要求：念起来有"稳感"，避免过于女性化
- 禁止：与知名言情男主同名或仅换姓

### 女主
- 公式 A：`单姓 + 柔字`（苏晚棠、林见夏、周予安）
- 公式 B：`单姓 + 双字`（程令仪、沈知微、许南枝）
- 禁止：与知名言情女主同名或仅换姓

### 配角
- 用**功能+性格**命名即可，不必人人主角感：如"毒舌闺蜜沈禾""护短大哥苏牧"

## 四、场景构词

### 现代场景
- 住宅：云顶公馆、临江壹号、梧桐里、半山墅（自创高端盘名，避免真实楼盘）
- 场所：集团总部、影视基地、私人会所、老城区咖啡馆、大学城、医院、法院、机场

### 古代场景（全部虚构）
- 宫城：承天殿、昭华宫、长宁宫、御花园、东宫、冷宫
- 府邸：将军府、丞相府、国公府、侯府、王府
- 市井：茶楼、酒楼、药铺、布庄、钱庄、驿站、码头、集市、庙会
- 禁止：真实宫殿名、真实朝代官署名、真实古城名

## 五、常见情节梗

契约婚姻、先婚后爱、带球跑、追妻火葬场、替身情人、白月光、朱砂痣、破镜重圆、误会、失忆、车祸、家族仇恨、商业联姻、门不当户不对、灰姑娘、重生复仇、手撕渣男、一路逆袭

### 反套路方向（避免同质化）
- 追妻火葬场 → 女主真的不回头，男主成长线独立完成
- 契约婚姻 → 双方都是理性人，先谈条款再谈感情
- 白月光 → 白月光本人出场，且不是恶毒女配
- 重生复仇 → 复仇完成后写"然后呢"，避免结局空心

## 六、写作红线

- 不美化家暴、囚禁、跟踪等违法行为（"霸道"不等于"犯罪"）
- 不写真实明星、真实豪门、真实案件影射
- 未成年人不写亲密关系
- 宫斗不写真实历史事件与真实人物
