# IP 与合规黑名单（生成前必检）

> 本文件是 sumeru-outline 合规检查的**基准数据**，也是 sumeru-finalize 文本扫描的规则来源。
> 生成世界观、人名、地名、势力名、招式名、公司名时，逐项比对；命中即判定为**致命问题**，必须替换后才能进入 write 阶段。
> 本清单为**非穷尽**清单。真正的判定标准只有一句：**读者能否一眼联想到某部具体作品、某个真实人物/地点/机构。**

## 一、判定标准（按严重度）

| 等级 | 定义 | 处理 |
|------|------|------|
| P0 致命 | 直接使用知名 IP 角色名/专有名词、真实公众人物、真实国家/城市/机构全称 | 必须替换，禁止发布 |
| P1 严重 | 谐音碰瓷（如把真实公司名改一个字）、真实地名的轻微改写、知名角色名拆字重组后仍可辨识 | 必须替换 |
| P2 中等 | 与某作品高度雷同的桥段组合（设定+人物关系+关键道具三件套同时撞车） | 建议重写为差异化版本 |
| P3 提示 | 通用题材词（如「金丹」「元婴」「系统」「签到」） | 可用，不属于侵权 |

### 2. 真实人物
- 历史人物、政治人物、当代公众人物、明星、运动员、企业家、作家、网红
- 真实人物的字号、道号、谥号、绰号
- 真实人物的"改一个字"版本（如把「苏轼」写成「苏试」）

### 3. 真实地点 / 机构 / 组织
- 国家、省、市、区、县、街道、山脉、河流、湖泊、岛屿、景点、古迹全称
- 真实学校、医院、公司、银行、法院、政府部门、军队番号、赛事、俱乐部
- 真实宗教场所与宗教人物（寺庙、道观、教堂、神祇名）
- 允许的例外：现实背景题材可使用**泛称**（如「帝都」「魔都」「南方某市」「集团总部」），但不得落到具体真实名称

### 4. 谐音碰瓷与拼贴
- 把真实公司改一个字（帝企鹅、阿里粑粑、碧桂花园、字节动力）→ 仍然侵权
- 把真实城市换成同音字 → 仍然违规
- 把两个知名角色名各取一半拼成新名 → 仍可能构成实质性相似

### 5. 敏感内容边界
- 民族、宗教、地域歧视性命名与设定
- 涉及现实政治事件、真实灾难、真实案件的影射
- 封建迷信的实操性描述（符咒步骤、祭祀流程、算命断语）→ 改为能量化/规则化解释
- 可复现的危险品配方、武器制造细节 → 一律模糊化

## 三、替换方法论（四步重构法）

1. **定音系**：先确定题材音系（古典单双字 / 现代口语 / 西幻音节 / 异域转写），避免混搭。
2. **拆意象**：从题材意象池取 1 个「姓/前缀」+ 1 个「核心字」+ 1 个「收尾字」。
3. **做变形**：换偏旁、换声调、换语序、用生僻但可读的字、用双字复姓。
4. **撞名检查**：搜索记忆 + 朗读测试（读出来像不像某个已有角色/真人）+ 三件套测试（名字+身份+金手指是否同时撞车）。

**示例（原创组合，可放心使用）**：
- 玄幻男：陆照野、江砚舟、楚怀朔、秦叙白、裴观澜
- 玄幻女：沈昭宁、姜绾绾、苏砚秋、云挽星、谢知微
- 道号：玄微子、清晏真人、碧霄真君、守拙道人
- 都市男：陈砚、周牧、许知远、林北、顾行舟
- 都市女：苏晚棠、林见夏、周予安、程令仪
- 西幻男：艾德里克、塞维恩、罗兰德、卡斯米尔
- 西幻女：艾琳娜、塞拉菲、薇薇安、伊莎朵拉
- 宗门：栖霞宗、听雪门、断岳剑派、沉星阁、归墟殿
- 城市：临川、望海、云栖、北岭、青梧、霜城

> 示例仅用于说明构词法，正式生成时应重新组合，不要整段照抄。

## 四、生成后自检（5 问）

1. 每一个名字，我能否说出它是怎么造出来的？（说不出 = 大概在照搬）
2. 是否存在"换了姓但名没换"的情况？
3. 势力名/公司名/赛事名是否只是把真实名称改了一个字？
4. 前三章出现的所有专有名词，是否都能在地名库/人名库中找到来源？
5. 把大纲给一个老读者看，他会不会说"这不就是某某书"？

5 问全部通过，才能把 `compliance-check.json` 的 `passed` 置为 `true`。

## 五、检查记录格式

保存到 `.sumeru/outline/compliance-check.json`：

```json
{
  "checkedAt": "2026-01-01T10:00:00Z",
  "scope": ["characters", "locations", "factions", "items", "skills"],
  "findings": [
    {
      "level": "P0",
      "category": "ip_character",
      "value": "被命中的名称",
      "location": "characters.protagonist.name",
      "reason": "与知名 IP 角色同名",
      "replacements": ["替换方案1", "替换方案2", "替换方案3"]
    }
  ],
  "replaced": 0,
  "passed": false
}
```

`passed` 为 `false` 时，禁止进入 sumeru-write 阶段。
