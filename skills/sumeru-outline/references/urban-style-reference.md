# 都市风格参考库

> ⚠️ 合规要求：现实背景题材可使用**泛称**（帝都、魔都、南方某市），但禁止出现真实城市、真实区县、真实公司/机构/银行/学校/部队名称，也禁止"改一个字"的谐音碰瓷。本文件提供构词法，不提供成品清单。

## 一、城市与区域

### 可用的泛称
帝都、魔都、羊城（泛称用法）、北方某市、江南小城、沿海新区、老城区、高新区

### 虚构城市构词
- 公式：`意象字 + 州/城/川/海/江`
- 示例：临川、望海、云栖、北岭、青梧、霜城、江宁、南屿
- 区县：`方位 + 城区/新区`（东城区、滨河新区、老城片区）——避免真实行政区名

### 场景
CBD、金融街、科技园、老城区、城中村、大学城、影视基地、码头、机场、医院、法院、别墅区、高档公寓

## 二、组织与公司

### 命名构词
- 公式：`意象字2个 + 行业后缀`（星辰科技、云海资本、万禾地产、远山传媒）
- 行业后缀：科技、资本、集团、控股、传媒、实业、生物、能源、物流
- 禁止：真实公司、真实银行、真实互联网大厂及其谐音变体

### 原创示例
星辰科技、云海资本、万禾地产、远山传媒、青梧生物、北岭能源（示例仅示范构词）

### 灰色势力
- 四大家族、隐世家族、古武世家（泛称可用）
- 具体组织名需自创：`意象 + 会/堂/社/局`（听潮会、青石堂、南屏社）

## 三、职业与身份

总裁、董事长、CEO、总经理、总监、经理、主管、程序员、产品经理、设计师、运营、市场、销售、教师、医生、律师、警察、特种兵、保镖、私家侦探、厨师、主播、电竞选手、投资人、基金经理、风水师、中医

> 涉及真实职业时，专业细节要准确，但不写可复现的违法操作。

## 四、人名生成法

### 男性
- 公式 A：`常见姓 + 单字`（陈砚、周牧、林北、许知远）
- 公式 B：`常见姓 + 双字意象`（顾行舟、沈叙白、江照野）
- 注意：避免"姓+名"恰好等于某位真实公众人物

### 女性
- 公式 A：`常见姓 + 柔字`（苏晚棠、林见夏、周予安）
- 公式 B：`常见姓 + 双字`（程令仪、沈知微、许南枝）

### 家族/豪门
- 姓氏要少而集中（一个家族一个姓），用"排行+辈分"区分人物（三叔、二房、长房长孙）
- 禁止直接使用真实豪门姓氏组合与真实家族故事

## 五、常见金手指

神医系统、神豪系统、签到系统、抽奖系统、读心术、透视、预知、重生、穿越、前世记忆、修仙归来、兵王归来、神医下山、龙王赘婿、鉴宝眼、直播系统、学霸系统

### 设计要点
- 都市金手指必须解决"为什么不暴露"的问题（低调动机、代价、规则限制）
- 金钱流要写**具体的商业逻辑**，不能只写"又赚了一个亿"
- 医术/鉴宝/法律等专业流，细节错一次就掉粉

## 六、常见爽点结构

1. **扮猪吃虎**：被轻视 → 亮身份 → 全场震惊
2. **打脸亲戚**：势利眼亲戚 → 主角出手 → 反转求饶
3. **商战翻盘**：资金链断裂 → 关键资源到位 → 反收购
4. **医术扬名**：疑难杂症 → 一针见效 → 大佬欠人情
5. **护短**：家人/朋友受欺 → 主角出手 → 立威

## 七、写作红线

- 不写真实公司商战内幕影射、不写真实案件改编（需大幅虚构化）
- 不写可操作的金融诈骗、黑客攻击、制毒制爆细节
- 官场、军警题材需架空化，避免真实机构与职务冲突
- 豪门恩怨不写真实家族，不写地域歧视
