# 西幻奇幻风格参考库
## 种族设定参考
### 常见种族
人类、精灵（森精灵/高等精灵/暗精灵）、矮人（山地矮人/锻造氏族）、兽人、龙族、半身人、地精、巨人、亡灵、恶魔、天使、泰坦、鱼人、蜥蜴人、翼人、兽耳种族（猫人/狐人/狼人）

### 种族特性速查
- 精灵：长寿、弓术与魔法天赋、亲近自然
- 矮人：锻造大师、嗜酒、固执重诺
- 兽人：体魄强横、崇尚武力、萨满信仰
- 龙族：傲慢强大、喜欢囤积财宝、血脉即力量

## 职业体系参考
### 职业列表
战士、骑士、法师、牧师、游侠、盗贼、刺客、圣骑士、死灵法师、德鲁伊、吟游诗人、炼金术士、附魔师、召唤师、魔剑士、狂战士、魔导工程师

### 等级划分（从低到高）
1. 见习 -> 正式 -> 精英 -> 大师 -> 宗师 -> 传奇 -> 神话
2. 一阶 -> 二阶 -> 三阶 -> ... -> 九阶 -> 圣域 -> 神境
3. 青铜 -> 白银 -> 黄金 -> 铂金 -> 钻石 -> 史诗 -> 传说（冒险者公会制）

## 魔法体系参考
### 魔法分类
元素系（火/水/风/土/雷/冰）、光暗系、时空系、召唤系、幻术系、附魔系、亡灵系、血脉魔法、符文魔法、神术（信仰驱动）、奥术（研究驱动）

### 法术环阶
一环戏法 -> 三环正式法师 -> 五环高阶 -> 七环大法师 -> 九环传奇 -> 禁咒（每环对应等级门槛）

## 势力参考
### 势力类型
帝国、王国、公国、教廷（信仰神明）、法师塔/魔法学院、骑士团、佣兵公会、冒险者公会、商会、盗贼行会、暗黑教派、龙巢

### 势力名称示例
洛兰帝国、艾伦特王国、圣辉教廷、晨曦魔法学院、苍穹法师塔、银鸢骑士团、黑鸦佣兵团、地精商贸联合会、暮色森林议会、龙眠山脉龙裔王庭

## 虚构地名参考
### 大陆/区域
洛兰大陆、暮色森林、迷雾湿地、咆哮山脉、龙眠山谷、死寂荒原、白霜冻土、落日海峡、风暴群岛、地底暗域（矮人国度）、浮空城遗迹
- 构词：`意象 + 地形`（灰烬荒原、银枝森林、断脊山脉、低语沼泽）

### 城市/据点
晨曦之城、灰石要塞、港城萨拉、秘银城、白塔城、十字镇、边境哨站、狮鹫驿站

## 虚构人名参考
### 男性译名风格
- 构词：`2-3 音节 + 姓`，音节表：艾/塞/罗/卡/维/莱/奥/西/加/亚 + 德/兰/恩/尔/斯/特/姆
- 原创示例：艾德里克、塞维恩、罗兰德、卡斯米尔、维克托、西奥多
- 禁止：知名西方奇幻/游戏角色名及其变体

### 女性译名风格
- 构词：`2-3 音节 + 娅/娜/琳/拉/尔`
- 原创示例：艾琳娜、塞拉菲、薇薇安、伊莎朵拉、诺艾尔、莉安娜
- 禁止：与知名角色同名

### 非人类命名风格
- 精灵：希尔凡、艾拉瑞尔、莱瑞安、银枝氏（长名可加父名/母名）
- 矮人：托尔姆、铁须、石锤氏族、铜砧氏族（氏族名 = 材质/工具 + 氏族）
- 巨龙：黑鳞王、晨曦之龙、暗渊龙母（称号式命名，不使用知名作品龙名）
- ⚠️ 禁止使用《魔戒》《冰与火之歌》《克苏鲁》等作品的种族名、地名、角色名及其改字版本
