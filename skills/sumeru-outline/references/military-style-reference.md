# 军事风格参考库

> ⚠️ 合规要求：军事题材敏感度最高。必须**架空国家、架空部队番号、架空战争背景**；禁止真实军队番号、真实现役装备参数、真实军事行动、真实军人姓名，也禁止使用军事影视作品的角色名。不写可复现的武器制造与爆炸物配方。

## 一、题材分类

军旅成长文（新兵到兵王）、特种兵文（小队作战）、谍战文（潜伏与情报）、架空战争文（虚构时空）、佣兵文（海外佣兵团）、末世战争文、星际战争文

## 二、部队体系

### 编制序列
方面军/集团军 → 军 → 师 → 旅 → 团 → 营 → 连 → 排 → 班

### 特殊部队（全部虚构）
- 构词：`意象 + 突击队/特战大队/小队/特勤组`
- 示例：龙焱突击队、利刃特战大队、暗夜之鹰小队、雷霆特勤组、蓝剑小队、幽灵侦察连
- 禁止：真实部队番号、真实特战单位名称及其"改一字"版本

### 晋升线
列兵 → 上等兵 → 下士 → 中士 → 上士 → 少尉 → 中尉 → 上尉 → 少校 → 中校 → 上校 → 大校 → 将官

### 技能徽章
狙击、爆破、潜水、伞降、通讯、医疗、格斗、驾驶、侦察

## 三、虚构势力与背景

### 国家/势力
- 主角方：龙夏国（示例）
- 对手方：北狼联邦、西岚帝国、南洋诸岛联盟
- 非国家行为体：黑鸦安保、灰熊集团、国际军火商、私人军事公司

> 国名要避免与真实国家同字或谐音；势力关系不要照搬现实地缘格局。

### 冲突背景
边境摩擦、海外撤侨、人质营救、反恐行动、维和任务、海盗清剿、政变干预、秘密渗透

## 四、人名生成法

### 男性
- 公式：`单姓 + 硬字`（冷奕、萧寒、顾剑锋、秦烈、陆战、韩铮、铁猛、周守疆）
- 军人名可带**代号**：`动物/自然 + 编号`（孤狼、山鹰、北风、07）

### 女性
- 叶知秋、唐笑笑、沈星然、林晚清（军医）、许念（通讯兵）、姜珂（情报官）

### 禁止
- 真实军人、真实英雄模范姓名
- 军事影视作品角色名及其变体

## 五、配角功能位

魔鬼教官、老班长（传帮带）、军医、技术兵、话痨炊事员、牺牲的战友（泪点担当）、幕后指挥官、跨国搭档、军嫂/家属

## 六、常见金手指

兵王系统/任务奖励、超强体能天赋、神枪手直觉、战场第六感、前世特种兵记忆、基因改造、外骨骼装甲（近未来）、战术预演能力

### 设计要点
- 军事文的金手指要**收敛**，否则会破坏"真实感"这一核心卖点
- 强项要有代价：伤病、心理创伤、社交障碍

## 七、经典桥段

新兵连挨整与逆袭、地狱周淘汰考核、老兵欺负新兵到刮目相看、首次实战怯场到爆发、狙击手对决、深入敌后营救、断后牺牲、退伍老兵重新入伍、演习吊打王牌部队、跨国联合军演、撤侨名场面、战友婚礼与遗物、军事法庭蒙冤昭雪

## 八、写作要点

- 核心爽点：纪律与热血、实力碾压、战友情谊、保家卫国的使命感
- 装备/战术描写要专业，但不写敏感参数、不写可复现的制造细节
- 主角成长线 = 军事技能 + 心智成熟双线并进
- 架空背景既降低合规风险，也解放剧情设计空间
- 牺牲桥段不要滥用，每次牺牲都要推动主角改变
