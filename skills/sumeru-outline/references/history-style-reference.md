# 历史架空风格参考库

> ⚠️ 合规要求：架空历史必须使用**完全虚构的朝代名、年号、人名、官署名**。禁止真实朝代 + 真实历史人物组合，禁止真实宫殿名、真实官职全称堆叠，禁止影射现实政治。

## 一、朝代与年号

### 架空朝代构词
- 公式：`大 + 单字`（大乾、大靖、大晟、大昭、大宸、大衍）
- 或 `方位 + 单字`（北朔、南岚、东临）
- 注意：不要与真实朝代同字（如直接用"大宋""大明"）

### 虚构年号
- 公式：`形容词 + 平/元/宁/和/光/德`（昭元、景隆、永定、承光、崇安、靖平、泰始、兴宁）
- 每个皇帝用一个年号，改元要有剧情理由

### 时代气质模板
- 类汉唐：开拓进取、万邦来朝、边患频繁
- 类两宋：商业繁荣、重文轻武、外敌压境
- 类明制：内阁党争、宦官干政、海禁倭乱（全部虚构化）
- 类魏晋：门阀垄断、清谈玄学、乱世烽烟
- 完全架空：自创历法、官制、科举制度

## 二、机构与官职

### 中央机构（虚构化）
- 沿用通用职能名可降低阅读成本：内阁、六部、翰林院、大理寺、御史台、枢密院、国子监、钦天监
- 特殊机构需自创：`意象 + 司/卫/府/营`（悬镜司、缇骑司、内卫府、暗桩营）

### 晋升线
文官：秀才 → 举人 → 进士 → 翰林编修 → 六部主事 → 郎中 → 侍郎 → 尚书 → 大学士
武官：百户 → 千户 → 指挥佥事 → 指挥使 → 都督佥事 → 都督

### 注意
- 官制要**自洽**：品级、俸禄、辖权不能互相矛盾
- 不要在一段里堆 5 个以上真实官职名，读者会晕

## 三、身份与阵营

### 身份
夺嫡皇子、落魄宗室、寒门学子、世家嫡子/庶子、外戚、权臣、清流言官、边关武将、质子、驸马、和亲公主、暗卫、密探

### 阵营
太子党、皇子党、世家门阀、寒门新贵、外戚集团、宦官集团、边军集团、清流文官、江湖势力

## 四、人名生成法

### 男性
- 公式：`单姓 + 双字`（裴昭、沈砚之、楚延年、陈元谨、崔明允）
- 世家子弟用**辈分字**：同一代共用中间字（如"承"字辈：李承稷、李承璋）

### 女性
- 公式：`单姓 + 柔字/双字`（谢知懿、崔莺时、陆令仪、宋清辞）
- 后妃/贵女可用封号 + 姓氏（如"宁妃崔氏"）

### 禁止
- 真实历史人物及其字号、谥号
- 真实历史人物的"改一字"版本
- 真实复姓 + 真实历史名人名的组合

## 五、常见金手指

穿越者的现代知识（玻璃、水泥、肥皂、白糖提纯、活字印刷）、重生改命、系统（签到/争霸/种田）、过目不忘、现代医学知识、军事地图先知、诗词文抄、知道历史走向

> ⚠️ 技术类金手指要写**落地难点**（原料、工匠、推广、既得利益阻挠），否则变成流水账。

## 六、经典桥段

九子夺嫡、科举连中三元、金殿对策、变法图强、党争倾轧、抄家流放再起、和亲与反和亲、开海互市、屯田养兵、盐铁之利、边关互市、天灾赈济、微服私访、退婚逆袭、赘婿拜相

## 七、常见冲突

皇权与相权、世家与寒门、文官与武将、改革与守旧、中原与边患、庙堂与江湖、忠臣与佞幸、储位之争、外戚干政、宦官专权

## 八、写作红线

- 不影射现实政治、不写真实民族冲突
- 不美化侵略战争、不写真实历史惨案的娱乐化改编
- 不写真实宗教冲突
- 虚构朝代也要遵守基本历史逻辑（交通、通信、财政、粮价）
