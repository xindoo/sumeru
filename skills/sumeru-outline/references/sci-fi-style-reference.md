# 科幻风格参考库

> ⚠️ 合规要求：可使用真实天文/物理概念（火星、曲率引擎、量子通信），但禁止使用知名科幻/影视/游戏作品独创的专有名词（如某作品的空间武器名、外星种族名、机器人名）。本文件提供体系模板与构词法。

## 一、星际设定

### 星域/星球
- 真实天体可用：火星、木星、土星、泰坦、比邻星、开普勒-452b
- 虚构星球构词：`希腊字母 + 星` / `意象 + 星`（阿尔法星、苍蓝星、灰烬星、霜环星）
- 禁止：直接使用知名作品独创的星球名、外星种族名

### 势力模板
- 政体：地球联邦、星际联盟、银河帝国、人类共同体、殖民地议会
- 组织：星际商会、探险公会、科研联合体、雇佣兵团、星际海盗
- 非人类：硅基文明、虫群意识、集群智能、机械教团（自创名称，不用知名 IP 种族名）

## 二、科技体系

### 文明等级
- 行星级 → 恒星级 → 星系级 → 河系级 → 宇宙级
- 卡尔达肖夫指数：I 型（行星能源）→ II 型（恒星能源）→ III 型（星系能源）

### 常见技术
曲率引擎、超光速航行、空间跳跃、虫洞、量子通信、量子传送、人工智能、机器人、机甲、星舰、歼星舰、能量护盾、隐形技术、纳米机器人、基因编辑、义体改造、脑机接口、虚拟现实、数字生命

### 设计要点
- 一项核心科技 + 一个明确代价（能耗、寿命、伦理、污染）
- 不要堆砌术语，读者只需要理解"能做什么、不能做什么"
- 战斗描写要遵守自己设定的物理规则

## 三、人名生成法

### 人类（中式）
- 男：陆昀、周砚、林拓、江叙白、沈砺
- 女：苏晚星、林知夏、程令仪、许南枝

### 人类（西式译名）
- 男：艾德里克、塞维恩、罗兰德、卡斯米尔、西奥多
- 女：艾琳娜、塞拉菲、薇薇安、伊莎朵拉、诺艾尔
- 构词：`音节表自由组合 + 姓`，避免与知名科幻角色同名

### 非人类
- 虫族：母巢、脑核、工虫、兵虫、王虫（泛称可用）
- 机械族：`功能 + 编号/代号`（观测者-7、织网单元、静默协议）
- 神族/高维存在：`意象 + 称谓`（晨星引路者、虚空低语者）

## 四、常见设定组合

### 金手指
主神空间式轮回、系统面板、重生、基因锁、精神力、念动力、超能力、魔法与科技结合、修仙与科技结合、末世废土、星际殖民、赛博朋克、蒸汽朋克、生物朋克

### 职业
机甲驾驶员、星舰舰长、特种兵、雇佣兵、科学家、工程师、医生、程序员、黑客、星际商人、星际海盗、探险家、考古学家、基因战士、改造人、变种人、异能者

### 常见冲突
- 人机伦理：AI 是否拥有权利
- 殖民与土著：开发还是保护
- 基因阶层：改造人与自然人
- 公司统治：企业取代国家
- 第一次接触：误判引发战争

## 五、写作红线

- 不写可复现的武器制造、生物武器配方
- 不写真实国家/军队的敏感装备参数
- 外星文明不影射现实民族与宗教
- 赛博朋克不美化犯罪与成瘾行为
