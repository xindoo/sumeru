# 灵异诡秘风格参考库
> ⚠️ 合规提示：灵异题材需注意「封建迷信」界限--推荐「诡异生物化/能量化/规则化」解释体系，避免直接宣扬超自然崇拜；民俗元素（纸人、阴婚等）需做虚构化与惊悚氛围处理。

## 题材流派参考
### 主流流派
- 诡异复苏流：现代世界诡异悄然降临，普通人逐渐察觉（当下热门）
- 规则怪谈流：遵守规则才能存活，规则之间存在矛盾与陷阱（当下热门）
- 民俗恐怖流：乡土民俗（纸扎、义庄、殡葬、老宅、祭祀）为底色
- 克苏鲁流：不可名状之物、理智值（SAN值）流失、越探究越疯狂
- 都市怪谈流：都市传说具象化（电梯、地铁、出租屋、深夜便利店）
- 收容管制流：神秘机构收容管理诡异（基金会式设定）
- 阴阳先生流：驱邪抓鬼的民间传承人视角

## 诡异等级/体系参考
### 诡异等级（从低到高）
1. 邪物 -> 凶物 -> 煞物 -> 灾物 -> 神话级诡异
2. E级 -> D级 -> C级 -> B级 -> A级 -> S级 -> 禁忌级
3. 白衣（初生）-> 红衣（成型）-> 黑衣（大凶）-> 无色（规则化身）

### 收容/管制机构（虚构命名）

## 规则怪谈模板
```
欢迎入住雾山旅馆，请务必遵守以下规则：
1. 入住期间请始终保持微笑
2. 如果前台接待没有影子，请立刻离开大堂
3. 凌晨两点到三点之间，无论听到什么，不要开门
4. 走廊尽头的房间不存在。如果你看到了，不要数房间号
5. 相信规则，但不要全信
```
（设计要点：规则间存在冲突，真规则保命，假规则杀人，最后一条埋反转）

## 写作要点
- 恐怖三要素：氛围（五感细节铺垫）、未知（信息节制释放）、代价（危险必须真实）
- 诡异文核心爽点：规则博弈的智斗感、以诡制诡的碾压感、真相揭晓的战栗感
- 克制血腥直白描写，多用心理压迫与环境暗示，兼顾平台合规
