# 仙侠风格参考库

> ⚠️ 合规要求：禁止使用真实宗教场所、真实道观寺庙、真实神祇体系，以及任何知名仙侠作品的角色名/门派名/法宝名。本文件只给结构模板与构词法。

## 一、修仙境界

### 主流体系
1. 练气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 飞升
2. 引气 → 开光 → 融灵 → 金丹 → 元婴 → 出窍 → 分神 → 合体 → 渡劫 → 地仙 → 天仙 → 金仙 → 仙帝
3. 凡人 → 修士 → 真人 → 真君 → 真仙 → 仙王 → 仙尊 → 道祖

### 设计要点
- 修仙文的核心是**寿元焦虑**与**资源稀缺**，境界必须绑定寿元上限
- 渡劫要有失败代价（身死、道消、转世），否则后期无张力
- 飞升之后要有新地图，否则大结局无处可写

## 二、门派/势力

### 类型
- 正道：剑修、丹修、符修、阵修、体修、器修
- 旁门：御兽、炼尸、血道、魅道、毒道、鬼修
- 中立：商会、拍卖行、情报楼、赏金榜

### 命名构词
- 前缀意象：栖霞、听雪、断岳、沉星、归墟、青梧、赤霄、玄微、苍梧
- 后缀：宗、门、派、阁、殿、宫、观、斋、洞天
- 原创示例：栖霞宗、听雪门、断岳剑派、沉星阁、归墟殿

### 禁止
- 不得使用真实宗教场所名（寺庙、道观、宫观）
- 不得使用真实名山、真实洞天福地名
- 不得使用知名仙侠作品的门派名

## 三、地名与秘境

### 构词法
- 山门：`意象 + 峰/岭/崖/谷`（落星峰、问剑崖、断魂谷）
- 秘境：`意象 + 墟/渊/海/渊/秘境/洞天`（归墟、幽澜渊、赤沙海、太虚秘境）
- 坊市：`意象 + 坊/市/城/渡`（青梧坊、落星渡、临川城）

### 原创示例
落星峰、问剑崖、归墟、幽澜渊、青梧坊、临川城、渡云津（示例仅示范构词）

### 禁止
- 真实名山大川、真实洞天福地、真实古城关隘

## 四、人名与道号

### 凡人姓名
- 男：`单姓 + 意象字`（陆砚舟、江叙白、裴观澜、沈砺）
- 女：`单姓 + 柔字`（沈昭宁、苏砚秋、云挽星）
- 复姓可用：上官、司徒、闻人、端木、澹台（避免整段照搬知名角色）

### 道号/法号
- 公式：`形容词 + 子/真人/真君/道人/上人`
- 原创示例：玄微子、清晏真人、碧霄真君、守拙道人、了尘上人（不要与真实宗教人物法号重合）

### 禁止
- 真实宗教人物、真实高僧大德、真实道士名号
- 神话体系中的既定神祇名（需要"神"设定时，请自创神名与神系）

## 五、法宝/丹药/符箓

- 法宝等级：法器 → 宝器 → 灵器 → 仙器 → 先天灵宝 → 混沌至宝
- 丹药：`功效 + 丹`（聚气丹、回元丹、洗髓丹、破境丹、九转还魂丹）
- 符箓：`属性/效果 + 符`（引火符、寒冰符、疾行符、隐息符、传送符）
- 灵药：`意象 + 草/芝/果/参`（月华草、赤髓芝、玄冰果、九节参）
- 禁止：直接使用某作品独创的法宝名、丹药名、异火名

## 六、常见剧情结构

1. **凡人流**：资质平庸 → 靠谨慎与算计活到最后 → 稳步攀升
2. **宗门流**：外门杂役 → 内门弟子 → 真传 → 掌门
3. **散修流**：无背景 → 靠机缘与交易 → 建立自己的势力
4. **重生流**：带着前世记忆 → 提前布局 → 弥补遗憾
5. **师徒流**：拜师 → 传承 → 师徒反目或护道

## 七、写作红线

- 不写真实宗教仪轨、不写可操作的修炼"功法步骤"
- 不把现实宗教人物写成反派或神祇
- 双修、夺舍等敏感设定需克制描写，避免低俗
- 境界突破必须有代价，不能无限白嫖
